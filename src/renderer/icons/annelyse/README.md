# Annelyse's Icon Bundle (GitHub #120, Gitea #469)

SVG source files for the toolbar icons, received from Annelyse on 2026-11-08.

| File                   | Icon                         | Used as                       |
| ---------------------- | ---------------------------- | ----------------------------- |
| `focus-mode.svg`       | Moon/crescent (thin stroke)  | Focus Mode (preferred)        |
| `focus-mode-thick.svg` | Moon/crescent (thick stroke) | Focus Mode variant (not used) |
| `autoscroll.svg`       | Arrow + circle               | Autoscroll                    |
| `font-decrease.svg`    | Magnifying glass + minus     | Decrease text size            |
| `font-increase.svg`    | Magnifying glass + plus      | Increase text size            |
| `add-bookmark.svg`     | Star + bookmark              | Add bookmark                  |

All SVGs are 1200x1200pt viewBox. Thin stroke is the preferred focus-mode variant.
